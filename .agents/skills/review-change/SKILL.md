# 审查变更

确认审查范围和可解析的比较基准；没有明确基准时查看当前已暂存及未暂存变更，说明范围。
初始仓库无提交时检查未跟踪的目标文件。不要假定 main 分支一定存在。
结合需求、调用方和相关规则读取 diff，不仅检查变更行本身。

优先报告影响实际行为的缺陷。每项给出优先级、文件位置、触发条件、影响及证据。
不把风格偏好、纯猜测或已由工具可靠检查的问题挤占主要结果。
审查默认只读；执行检查前判断是否写入数据或修改工作区。

没有发现时明确说“未发现可确认缺陷”，并说明未覆盖的运行环境或验证限制。
