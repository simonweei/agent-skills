# 建立项目上下文

读取根目录 AGENTS.md、docs/ai/PROJECT.md 及已有 README、依赖清单、入口和 CI。
区分空工程与已有项目，不用模板覆盖已有架构或用户文件。

根据需求确定目标、首版范围、验收标准和运行环境。能够从代码确认的信息直接填写；
只有影响下一步实现的缺失信息才询问，其余标记为待确定。

更新 docs/ai/PROJECT.md，命令必须来自真实项目配置或实际验证。保留有用决策。
当用户要求实现项目时，继续完成一个最小端到端流程及相关验证；只要求规划时不扩展为实现。
业务项目建立后，将 AGENTS.md 中“本模板维护命令”替换为项目实际命令。

输出项目状态、可运行方式、首个验收结果和下一步。不要把模板检查当作产品测试。
