# Agent 分工规则

默认一个主 Agent。用户要求分工，或当前环境允许且任务适合时，再使用子 Agent。

| 角色 | 输入 | 输出 | 文件权限 |
| --- | --- | --- | --- |
| explorer | 一个具体调查问题 | 路径、证据、未知项 | 只读 |
| implementer | 目标、验收标准、文件范围 | 修改和验证结果 | 分配范围内 |
| reviewer | 基准版本、diff、需求 | 按影响排序的缺陷 | 只读 |

- 主 Agent 负责需求、接口约定、集成和最终验证；无需另建一个主 Agent 配置。
- 并行实现先划分文件归属，共享文件由主 Agent 集成。
- 有先后依赖的步骤按顺序执行。短任务直接完成，避免分工成本超过收益。
- `.codex/agents/*.toml` 是 Codex 角色配置；其他工具可以手工复用其职责说明，但不会自动识别该目录。
- 不固定模型名称、服务商或权限，沿用使用者的环境；不保证所有客户端版本支持自定义 Agent。
